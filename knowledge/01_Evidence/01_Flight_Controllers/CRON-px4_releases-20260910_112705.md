## What's Changed

This is a pre-release for flight testing, [full release notes can be found here](https://docs.px4.io/main/en/releases/1.18).

Fixes since beta1:

* Fixed-wing: NaN eas2tas from zero-airspeed division in lat/lon control ([#28107](https://github.com/PX4/PX4-Autopilot/pull/28107)), tailsitter false quadchute from wrong attitude frame ([#27834](https://github.com/PX4/PX4-Autopilot/pull/27834))
* QGC compatibility regressions from stricter command validation: multicopter guided takeoff, camera mission items, and VTOL landing patterns are accepted again ([#27853](https://github.com/PX4/PX4-Autopilot/pull/27853), [#28079](https://github.com/PX4/PX4-Autopilot/pull/28079))
* SD card read corruption on STM32H7 boards fixed via NuttX SDMMC cache coherency ([#28071](https://github.com/PX4/PX4-Autopilot/pull/28071))
* Parameter storage: FMUv6X-RT FRAM multi-page writes ([#28127](https://github.com/PX4/PX4-Autopilot/pull/28127)), flashparams compaction moved to boot ([#28093](https://github.com/PX4/PX4-Autopilot/pull/28093))
* FMUv6X-RT: boot-time FlexSPI DLL calibration, fixing load-dependent hardfaults ([#28141](https://github.com/PX4/PX4-Autopilot/pull/28141))
* Estimator: external position estimate hard reset while aiding is active ([#27856](https://github.com/PX4/PX4-Autopilot/pull/27856)), DroneCAN rangefinder out-of-range readings no longer fused as terrain ([#27963](https://github.com/PX4/PX4-Autopilot/pull/27963))
* Navigation: DO\_JUMP set as current mission item is resolved to its target ([#28063](https://github.com/PX4/PX4-Autopilot/pull/28063))
* Battery: unknown time-remaining no longer trips RTL ([#27929](https://github.com/PX4/PX4-Autopilot/pull/27929)), coulomb counting uses unclamped dt ([#27866](https://github.com/PX4/PX4-Autopilot/pull/27866))
* Commander: COM\_PARACHUTE warning-only mode ([#27903](https://github.com/PX4/PX4-Autopilot/pull/2790
